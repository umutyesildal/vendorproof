01 — The problem

AI research tools invent citations.

The claim

"Vendor X suffered a major data breach in March 2024."

The cited source

never mentions a breach. It's a pricing page.

A URL next to a claim is not evidence.
Procurement decisions need receipts, not vibes.

02 / 07
OBJECTION PREP — "isn't this just RAG?" RAG retrieves text and trusts the model's summary of it. We verify the claim's quote literally exists inside the cited source — deterministic, not probabilistic. If judges push: "the hard part isn't the string match — it's forcing the LLM to emit verifiable claims in the first place."
02 — How it works

The model proposes.
Deterministic code disposes.

StageWhat happensTrust
PLANNER Nemotron 3 Ultra writes its own 3–4 search queries probabilistic
COLLECTOR Tavily Search, equal share per query → dedupe → Extract full text deterministic
VERIFIER The model drafts claims — each with a source URL and a verbatim quote probabilistic
VALIDATOR URL was really extracted · quote exists in that page · page names the vendor can only downgrade

A claim that fails any check drops to insufficient_evidence. Nothing is ever upgraded. insufficient_evidence is a valid answer.

KEY LINE "The model proposes; deterministic code disposes." This is the moat sentence — slow down on it. The validator is plain JavaScript in one n8n Code node: it can strip a citation, downgrade a claim, or flag review. It can never upgrade.
